# 《说谎的爱人》8 分钟先导片段 · 生产手册

**目标**：用最小成本验证数字人方案能不能撑起这部片子，再决定是否投全片。
**范围**：场 12—23（大理段落），89 镜 / 492 秒。
**已完成**：镜头表、光照实算、生图与运动提示词、动态分镜成片。
**待你执行**：68 个数字人镜头的生成与替换。

---

## 一、为什么选大理段落做先导

| 理由 | 说明 |
|---|---|
| **角色最少** | 只需 **林见月、陈亦** 两个 LoRA（老板娘、船家为背景群演，可用无 LoRA 出图）。全片六个角色只训两个，GPU 成本降到 1/3 |
| **场景最集中** | 码头、客栈、苍山、蝴蝶泉、船上、房间——都是自然光或单一光源，是数字人最容易做对的光照条件 |
| **情绪跨度最完整** | 从初见的克制到关灯前的失控，八分钟里走完一条完整的情感曲线。**如果这八分钟不成立，全片就不用做了** |
| **含全片最难的两个镜头** | `15-06`（隔着两寸不碰）与 `19-04`（那个吻）——这两镜是对"数字人能不能演戏"最严苛的检验 |
| **天象窗口已锁定** | 场 18 的满月经天文实算，照亮 99.8%、方位 120.6°，月光带正落在人物面前。这是全片视觉最有说服力的一镜 |

## 三、执行步骤

### 步骤 1 · 立两个角色的脸（L1）

```bash
cd screenplay/pipeline
python3 characters.py --sheet 林见月 --jsonl ljy_train.jsonl
python3 characters.py --sheet 陈亦   --jsonl cy_train.jsonl
python3 comfy_submit.py ljy_train.jsonl
python3 comfy_submit.py cy_train.jsonl
```

各出 40 张，**人工挑 8 张最一致的**。这 8 张就是该角色的原创面孔基准。

> ⚠️ 参考图必须是这一步生成的虚拟脸，不要投真人照片。

### 步骤 2 · 训 LoRA（L3，先导片段直接上 L3，跳过 L2）

```
kohya_ss FLUX LoRA
  素材：用 L1 的 8 张基准图，经 PuLID 扩到 35—50 张多角度多光位
  参数：network_dim 32 / alpha 16 / lr 1e-4 / batch 2 / epochs 12 / ~1800 steps
  触发词：ljy_woman  /  cy_man
```

先导片段只有 68 镜，一致性要求高于探索速度，**建议直接训 LoRA，不走 L2**。

### 步骤 3 · 出 68 个关键帧

```bash
python3 pilot_shots.py --jsonl pilot.jsonl
python3 comfy_submit.py pilot.jsonl --filter 林见月 --lora ljy_v1.safetensors
python3 comfy_submit.py pilot.jsonl --filter 陈亦   --lora cy_v1.safetensors
```

导出的每条记录已包含：镜号、入点时码、时长、LoRA 触发词、
完整提示词（统一影调 + 角色基准 + 阶段造型 + 本镜内容）、负面提示、
分辨率 1920×816（2.39:1）、固定 seed。

### 步骤 4 · 每镜过检

按 `说谎的爱人-真实性校验规范.md` 的五层红线逐镜过检。
**本段落的高危项**：

| 镜号 | 必须核对 |
|---|---|
| `15-04` `17-03` | 婚戒为**真戒**（铂金，反光锐） |
| `17-06` 起 至 `20-06` | 左手无名指**必须为空** |
| `21-04` 起 | 改为**镀白金银戒**（反光更漫、边缘更钝） |
| `12-04` `13-03` `14-04` `15-03` `16-04` `23-02` | 陈亦**必须有遮挡物**，不得出现无遮挡正面单人镜头 |
| `19-05` | 右手抓衬衫下摆，指节发白——这只手七个月后会被割断肌腱 |
| 全部大理镜头 | 见月造型为「hair down + 高原红 + **第一次出现笑纹**」，这是她全片唯一放松的阶段 |

红线项预计一次通过率 30—45%，已计入"6 选 1"。

### 步骤 5 · 图生视频

```
Wan2.2-I2V-A14B，每镜 5s，720p
运动提示词直接取 pilot.jsonl 的 motion 字段
```

`motion` 字段是**逐镜写的表演指令**，不是通用词。例如：

- `16-04`：`a micro-pause before the mouth moves — the pause must be visible`
  （陈亦第一次说谎前那半秒迟疑，是全片最重要的表演指令）
- `15-06`：`the arm comes in slowly and stops; the gap is the subject of the shot`
  （拍的是那两寸距离，不是那条手臂）
- `21-05`：`the hand drops slightly faster than it should — it weighs less`
  （全片唯一一次让观众用眼睛看见重量差）

### 步骤 6 · 替换镜头卡

动态分镜的时间轴**精确到帧**，按镜号逐条替换即可，时间轴不动：

```
render/说谎的爱人-先导片段-动态分镜.mp4   ← 当前成片
  ├ 21 个 proc 空镜   已是真实画面，可直接用于正片
  └ 68 个 dh 镜头卡   用你生成的视频按镜号替换
```

若某镜生成后长度不足 5 秒，**不要改时间轴**——优先重生成或用尾帧定格补足。
剪辑节奏是这条动态分镜已经验证过的东西，是先导片段最有价值的产出。

### 步骤 7 · 配音与成片（用本仓库 NarratoAI）

```bash
cd ../..
uv sync && uv run webui.py
```

台词表直接取分镜表的「台词」列。TTS 建议 IndexTTS-2。
配乐已随动态分镜生成（`render/pilot_score.wav`），可直接沿用或替换。

## 四、验收标准

先导片段做完后，用这五条判断值不值得投全片：

1. **脸稳不稳** —— 68 镜里同一角色的脸，能不能一眼认出是同一个人
2. **手崩不崩** —— `15-04`（手贴玻璃）、`17-08`（捞三次）、`19-05`（攥衬衫）、`21-04`（举戒指）这四个手部特写，是全片手戏密度最高的地方
3. **两寸成不成立** —— `15-06` 那条不碰的手臂，观众有没有屏住呼吸
4. **半秒看不看得见** —— `16-04` 陈亦说谎前的迟疑，能不能被表演出来
5. **月亮对不对** —— `18-01` 的满月方位与月光带，是否与实算一致

**前四条任一不过，就不要投全片**——问题不在算力，在当前模型对微表演的还原度。
第五条不过只是提示词没写对，改了重出即可。
