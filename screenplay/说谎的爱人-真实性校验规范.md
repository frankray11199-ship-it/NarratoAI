# 《说谎的爱人》数字人真实性校验规范

**适用范围**：全部 AI 生成镜头（静帧与视频）在进入剪辑前的强制过检
**校验层级**：L1 肢体动作 · L2 面部与微表情 · L3 物体交互 · L4 环境与自然规律 · L5 场景与剧情互证
**判定原则**：任一 **红线项**不通过即废片重生成，不做后期补救

---

## 〇、为什么必须逐镜过检

AI 生成人物的失真不是"画质问题"，是**行为学问题**。观众说不出哪里不对，但会本能地不信。
失真集中在六处：**手、重心、视线、呼吸、接触面、连续性**。
本规范把这六处拆成可肉眼判定的条目。

## L1｜肢体动作真实性

### 🔴 红线项（一票否决）

| # | 检查项 | 常见失真 | 判定方法 |
|---|---|---|---|
| 1.1 | **手指数量与关节** | 六指、缺指、关节反向弯曲、指节长度失调 | 逐帧放大到手部 200%，数指头，看每个指节的弯曲方向 |
| 1.2 | **重心与支撑** | 人站着但重心不在支撑脚上；坐着但骨盆不在座面上；蹲姿脚跟离地却无前倾代偿 | 画一条铅垂线过头顶，检查是否落在支撑面内 |
| 1.3 | **关节活动度** | 肘/膝反关节、颈部超过 ±70° 旋转、肩胛不随手臂抬升 | 对照人体活动度上限：肘 0—150°，膝 0—135°，颈旋转 ±70° |
| 1.4 | **肢体数量与连接** | 多出的手臂、衣物下多出的腿、手臂穿过躯干 | 全身扫查，特别注意衣物遮挡区 |
| 1.5 | **步态周期** | 双脚同时离地（非跑跳）、摆臂与迈步同侧、脚掌与地面不接触 | 逐帧看足底与地面的接触关系 |

### 🟡 警戒项（可修，需复核）

| # | 检查项 | 本片专项要求 |
|---|---|---|
| 1.6 | 呼吸可见性 | 静态镜头中胸廓/肩部必须有微幅起伏。**周砚全片肩部起伏幅度须大于常人**（哮喘设定），场 68 须为明显的辅助呼吸肌参与 |
| 1.7 | 无意识微动 | 眨眼（正常 15—20 次/分）、吞咽、重心微调、手指小动作。全静止＝假 |
| 1.8 | 动作起止 | 真人动作有**预备—执行—收势**三段。AI 常直接切入执行段，显得像被拽动 |
| 1.9 | 惯性与配重 | 转身时头先动、躯干后跟；提重物时对侧肩下沉 |
| 1.10 | **本片专项：见月右手** | 场 69 之后所有镜头，右手须呈现**静止性震颤**（4—6 Hz，幅度小、频率稳），且**只在做精细动作时加剧**。若整只手大幅乱抖＝错误，那是帕金森样表现，不是肌腱损伤 |
| 1.11 | **本片专项：见月的职业体态** | 常年伏案毫米级作业 → 含胸、颈前倾约 15°、低头视角固定。场 12—23 大理段落应**短暂消失**（她放松了），场 79 之后**永久性加重** |
| 1.12 | **本片专项：陈亦的遮挡** | 每一个镜头都必须有前景遮挡物。若出现完全敞开的正面单人镜头＝违反设定，废片 |

## L2｜面部与微表情

### 🔴 红线项

| # | 检查项 | 判定 |
|---|---|---|
| 2.1 | 双眼视线汇聚 | 两眼视轴必须交于同一点。AI 常出现"散视"——左右眼各看各的 |
| 2.2 | 牙齿与口腔 | 牙齿数量、排列、上下咬合面；张口时须见舌与口腔深度，不能是贴图 |
| 2.3 | 耳朵对称性与形态 | 双耳高度差、耳轮结构崩坏 |
| 2.4 | 面部左右一致性 | **不是要求对称**——真人脸本就不对称。要求的是**同一个人的不对称在所有镜头中保持一致**（见月左下颌那颗痣必须每镜都在同一位置） |
| 2.5 | 口型与台词 | 有台词镜头须做 LatentSync 对齐；重点核对唇齿音（f/v）、双唇音（b/p/m）、圆唇（u/o） |

### 🟡 警戒项

| # | 检查项 | 本片专项 |
|---|---|---|
| 2.6 | 表情的肌肉逻辑 | 真笑（杜氏微笑）眼轮匝肌参与、有眼角纹；假笑只有颧大肌。**见月全片只有场 12—23 出现真笑，其余全部是假笑**——这是可验证的硬指标 |
| 2.7 | 眼动 | 注视点须有微跳视；说谎时的目光回避须是"短暂移开再回来"，不是"长时间飘" |
| 2.8 | 泪液物理 | 泪水沿鼻侧沟流下，不是从眼角直线下坠；哭后须有眼睑水肿与鼻头充血 |
| 2.9 | 皮肤 | 必须有毛孔、汗毛、色斑不均。**磨皮＝废片** |
| 2.10 | 年龄跨度 | 见月 34 岁（场 1—103）与 43 岁（场 104—112）须同人可辨但明显老化：法令纹加深、上睑下垂、皮肤失去光泽、发际线后移 |

## L3｜物体交互（AI 最易崩的一环）

### 🔴 红线项

| # | 检查项 | 判定 |
|---|---|---|
| 3.1 | **接触面形变** | 手握杯子，手指须贴合杯壁并有轻微软组织压扁；坐沙发，坐垫须凹陷。**物体穿手／手悬空握物＝废片** |
| 3.2 | 遮挡关系 | 手在物前则物被遮，不能半透明；物在手前则手指被截断 |
| 3.3 | 重量表现 | 空碗与盛水的碗，手腕角度、前臂肌肉张力不同 |
| 3.4 | 工具的正确握法 | **描金笔须为执笔式（拇指、食指、中指三点），不是握拳**。见月是职业修复师，握法错误＝人物崩塌 |

## L4｜环境与自然规律

### 🔴 红线项（已用 `pipeline/astro.py` 计算验证）

| # | 检查项 | 判定 |
|---|---|---|
| 4.1 | **光源方向唯一性** | 同一镜头内所有人物与物体的投影方向必须指向同一光源。多光源须各自成立 |
| 4.2 | **阴影与光照强度匹配** | 硬光配硬边阴影，柔光配柔边。阴天出现硬阴影＝废片 |
| 4.3 | **太阳高度角** | 见下方天文校验表。日高 6.9° 的斜射光不能拍成正午顶光 |
| 4.4 | **月相与月位** | 见下方天文校验表。**这是本片已实际查出并修复过一次硬伤的项目** |
| 4.5 | 水面反射 | 反射像必须在**光源方位角方向**上。月亮在西、人朝东看湖，月光带不会出现在她面前 |
| 4.6 | 水的物理 | 涟漪由扰动点向外；风浪方向与旗帜/头发/树叶一致 |
| 4.7 | 雨雪风向一致 | 雨丝倾角、人物头发、衣摆、水面波纹须同向 |

## 六、过检流程（每镜必走）

```
生成镜头
   ↓
① L1 肢体红线 5 项  ──不过──> 废片，重生成（换 seed / 加 FaceDetailer / 改提示词）
   ↓过
② L2 面部红线 5 项  ──不过──> 废片
   ↓过
③ L3 交互红线 4 项 + 高危道具核对 ──不过──> 废片
   ↓过
④ L4 环境红线 7 项（对照天文校验表）──不过──> 废片
   ↓过
⑤ L5 状态连续性矩阵比对 ──不过──> 废片
   ↓过
⑥ 警戒项复核，可修则修
   ↓
入库，进剪辑
```

**统计预期**：按同类项目经验，红线项一次通过率约 30—45%，
即平均每个可用镜头需生成 2.5—3.5 次。前文工作量估算中"600 镜 × 6 选 1"已包含此损耗。

## 七、可自动化的部分

| 检查项 | 自动化方案 |
|---|---|
| 4.3 / 4.4 天文 | ✅ **已实现**：`pipeline/astro.py`，可对任意日期/时刻/地点算出日月位置与月相 |
| 1.1 手指、1.3 关节 | MediaPipe Hands / OpenPose 关键点检测 + 关节角度阈值判定，可脚本化 |
| 2.1 视线汇聚 | L2CS-Net 视线估计，判定双眼视轴夹角 |
| 2.4 面部一致性 | InsightFace 提取 embedding，与角色基准图算余弦相似度，阈值 < 0.62 判为变脸 |
| 4.1 光源方向 | 人物法线估计 + 阴影方向聚类，一致性检验 |
| 5.5 年龄一致 | 年龄估计模型，跨镜头方差检验 |
| L5 状态矩阵 | 元数据标注 + 脚本比对（每个镜头打上场次号，自动查表） |

**其余项目须人工过检**——尤其是 1.8 动作起止、2.6 真笑/假笑、3.1 接触面形变，
这三项目前没有可靠的自动判据，而它们恰恰是"像不像真人"的决定性因素。
